# Git commits

## Workflow

- **Never commit unless the user explicitly asks**
- Always commit all files: `git add .`
- After finishing a commit, always push

## Commit message format

- **Title**: English, imperative, conventional commits
  - Examples: `feat:`, `fix:`, `refactor:`, `chore:`, `docs:`, `test:`, `style:`
- **Body**: 2–4 lines, what and why, in English
- Always add:
  ```
  Co-Authored-By: Z.GLM <noreply@glm.com>
  ```
