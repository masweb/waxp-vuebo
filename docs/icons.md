# Icons

App icons using **Tabler Icons for Vue**.

## Library

`@tabler/icons-vue`

## Import

Import individual components as needed:

```ts
import { IconSunFilled, IconMoonFilled } from '@tabler/icons-vue'
```

## Usage in template

```vue
<IconSunFilled :size="24" stroke-width="1.2" />
<IconMoonFilled :size="22" stroke-width="1.2" />
```

## Common props

| Prop | Type | Description |
|------|------|-------------|
| `size` | number | Icon size (e.g. 24) |
| `stroke-width` | number | Stroke width (e.g. 1.2) |
